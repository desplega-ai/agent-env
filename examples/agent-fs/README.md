# agent-fs

Run real agent-fs acceptance through the installed public agent-env SDK.
The workflow exports a source checkout and generates private fixture credentials.
It checks authentication, source updates, CLI operations, S3 versions, persistence, and purge.

See [the guide](../../docs/agent-fs.md) for commands and isolation details.
See [verification evidence](https://github.com/desplega-ai/agent-env/blob/master/examples/agent-fs/VERIFICATION.md) for the tested revision and results.
